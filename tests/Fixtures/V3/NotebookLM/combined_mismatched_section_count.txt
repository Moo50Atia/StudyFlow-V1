Lecture: W1 | The Number Line and Real Numbers

Section 1:
Section Identity: Real Number Representation
Core Understanding: Every real number corresponds to a unique point on a continuous line.
Visual-First Explanation: A continuous line with an origin point 0 extending infinitely in positive and negative directions.
Visual Scene Script: Number line renders from -10 to +10.
Dynamic View Blueprint: Interactive 1D coordinate axis.
Visual Learning Outcome: Learner sees density of real numbers.
Concept Check: Is there an empty gap between rational numbers?
Conceptual Summary: Real numbers form a complete continuum without gaps.

Section 2:
Section Identity: Order and Absolute Value
Core Understanding: Order corresponds to position.
Visual-First Explanation: a < b means a is left of b.
Visual Scene Script: Two points slide.
Dynamic View Blueprint: Dual sliders.
Visual Learning Outcome: Distance is absolute value.
Concept Check: Why distance is positive?
Conceptual Summary: Absolute value is distance.
