Lecture: W2 | Ordered Pairs and Coordinates

Section 1:
Section Identity: Cartesian Coordinates and Orthogonal Projection
Core Understanding: An ordered pair represents a unique coordinate position in a 2D plane.
Visual-First Explanation: Two intersecting perpendicular lines forming quadrants where points are projected onto each axis.
Visual Scene Script: 2D grid appears with x and y axes. An ordered pair (3, 2) is plotted with drop-lines to axes.
Dynamic View Blueprint: 2D plane canvas with interactive point handle and dynamic coordinate readouts.
Visual Learning Outcome: Student sees order matters: (2, 3) is distinct from (3, 2).
Concept Check: Why is (x, y) different from (y, x) when x != y?
Conceptual Summary: Cartesian coordinates map 2D space bijectively to real number pairs.
