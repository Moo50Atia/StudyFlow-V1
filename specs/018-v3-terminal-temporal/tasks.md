## Implementation strategy and checkpoints

Foundation plus US1 is the first useful automatic fixture-backed slice; do not run an unattended paid batch before US2 uncertainty/ownership/control gates. US3 supplies full monitoring/restart/rotation evidence. US4 supplies the saved-result path. All local gates T030/T032 are required for local completion. G-LIVE separately proves the selected actual account/model; skipped G-LIVE prevents a fully live-verified claim but does not erase passing local evidence.
