## Cross-record and transaction rules

The projector starts from an owner-authorized `v3_processing_cases` row or an admin-safe query; all child records are filtered by `case_id` and checked against their exact parent FK and current-pointer semantics. It never loads a generic Eloquent relation into an admin serializer. Approval trace walks `v3_approved_scenes.review_decision_id → v3_teacher_review_items.candidate_id/qualification_id → v3_scene_candidates → v3_authoring_requests → v3_scene_prompt_versions → v3_teacher_sections → v3_lesson_maps → v3_knowledge_source_bindings/v3_extracted_sources → v3_documents`, verifying captured 005 settings and 012 check/JEV references. Branches come from committed attempts/routes, not guessed latest records. A missing dependency yields a fixed gap code, with no content fallback.

Export generation runs on a stable DB snapshot, computes allowlisted JSON, stages and hashes it on `v3_private`, and inserts `ready` export/audit rows in one DB transaction before returning an ID. No network call occurs inside that transaction. A rollback may leave an unreferenced file for the 24-hour orphan cleaner; it cannot leave a downloadable row with incomplete bytes. Exact same actor/key/body replay returns the existing ID after fresh auth. A changed replay is 409. Download rechecks actor, role, case owner where applicable, expiry and SHA-256, and inserts a download-attempt audit before streaming; a failed audit returns 503. A client disconnect after headers does not prove delivery.

## Retention and recovery

`pilot-retain-v1` keeps all 006–014 referenced and unresolved evidence. 015 never interprets 014 `deferred_to_015` as permission to delete. Export snapshots expire 15 minutes after creation and their files are safely removed after 24 hours only after confirming the row/path relationship. Missing/corrupt underlying private content is a gap and operational alert; no report hides it or tries to reconstruct it from a provider. Admin receives a count/code only. A corrupt export file returns a fixed 503 and retains the audit row for investigation.
