# Implementation Notes: 015

Read the direct [execution plan](task-execution-plan.md) for order/checkpoints; these notes cover traps in this repository.

- Today the repository is V2 Laravel 12 with no V3 migrations/routes/worker. `app/Http/Middleware/TeacherAccessMiddleware.php` lets an admin through V2 content; it is not an 004 V3 original-owner check. Add 015 routes only to 004's `routes/v3.php`, and test real 006/009/013 routes for alternate-path isolation. `config/filesystems.php` currently has a `local` disk with `serve=true`; all V3 evidence and export JSON belongs on 006's non-served `v3_private` disk.
- Use the 013 `v3_review_section_states.current_approval_id` to count a current approved scene. An immutable `v3_approved_scenes` row proves a historical decision even after correction/cancellation; it does not prove current deliverability. A 014 cancellation clears current pointers while preserving historical rows.
- The 009 First-step Section text has eleven stored fields; the evidence graph refers to the Section ID and exact query/map, while the existing owner route remains the content reader. Do not copy the fields into 015 JSON or admin DTO. NotebookLM is the mapping/research source; JEV Choice/Score/Noul values are prior typed decisions. No 015 model re-judges them.
- A source/answer/scene/note path or SHA-256 is internal verification material, never a JSON field. Verify against the private disk before advertising `available`; render a fixed gap on mismatch. The 24-hour 006–013 orphan cleaners are restricted to unreferenced files and are not pilot retention jobs.
- `created_at`/`updated_at` is not a universal provider timer. 007 event time is Laravel commit time, 013 `ready_at→decided_at` is wait, and 011 `duration_ms` is a separate selected-provider observation. Keep them separately named in reports. Exact duplicated callbacks do not add attempts. `process_again` creates a new case but may reuse Document bytes.
- `cost_minor_units` on 011 is nullable and provider reported; it is not a full case invoice. NotebookLM, JEV, checker infrastructure and human labor may lack charge data. Show subtotal and unknown components; never label a partial subtotal as full cost. No active rate card exists in 005, and a price estimate cannot be inserted from model names or token counts.
- Build the admin output from a closed scalar allowlist before rendering or serializing, as 004 requires. Do not eager-load a teacher graph and remove fields afterward. A unique private sentinel in every content type should be absent from actual admin HTTP/export bytes and logs in H15.
- A 014 deletion assessment is an immutable snapshot, not authorization. `pilot-retain-v1` retains all referenced/uncertain educational evidence. 015's only deletion job is for its own expired export JSON. Missing private bytes are an incident (`missing_or_corrupt`), not a tombstone.
- Laravel's routine `phpunit.xml` uses SQLite `:memory:`. The same-key export race needs independent processes/connections on one transactional database and a barrier proving overlap. A sequential retry assertion is necessary but not concurrency evidence.
