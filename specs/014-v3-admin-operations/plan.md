## Repository fit

The inspected application is Laravel 12/PHP 8.2 with `routes/web.php` V2 `/users`, `/sections`, `/lectures`, study-flow and dynamic API routes. `UserController` currently creates, updates and deletes users directly; the 004 prerequisite must first replace role/access effects with `ChangeAccountAccess` and retain enrolled accounts. `TeacherAccessMiddleware` allows admin/student V2 content reads and is never an authorization path for V3 content. `bootstrap/app.php` has no V3 API loader today, and `phpunit.xml` uses in-memory SQLite. There is no V3 case, workflow, bridge, review or admin operation code yet. 014 uses delivered 004–013 services after their implementation, not a parallel V2 status or role model.

## Ordered decisions

1. Start with 004-safe scalar queries. The 014 wrapper never serializes a case/review/effect model; `GET /health` performs one bounded signed Temporal RPC and labels provider health unknown. Do not add an admin export; 015 consumes a closed projection.
2. Persist `AdminCommand` and `CaseOperationControl` with case-scoped idempotency, version compare and atomic audit. Hold/resume use a separate control version, not 007 case-event sequence. A hold/cancel request fences new claims in the same case transaction before bridge delivery. Integrate the guard into the real stage-claim services and 013 decision boundary, including already-running workflow branches.
3. Extend the 007/013 workflow code with deterministic versioned admin-control signals. The signed callback proves hold/resume/cancel consumption. Cancelled case state requires the committed command and matching callback or the no-workflow local proof. A lost acknowledgement is queried with the same command ID; no restart of `v3-case-{case_id}` or a correction workflow.
4. Implement `retry` only through the six allowlisted same-operation reconciliation adapters. This is a read/verification or already-idempotent signal action, never a second NotebookLM create/add, prompt/coding provider send, JEV override, new repair budget or terminal workflow restart. Unsupported blocked outcomes remain blocked and explicitly conflict.
5. Post one fixed in-app reminder for a Section-current dormant 013 item. Test 004 provisioning and access mutation via their real V2/V3 routes; do not duplicate their service. Record a no-delete pilot assessment, with 015 responsible for any later execution.
6. Run actual 004/V2 boundary regression, two-process shared-DB races, controlled in-flight result tests and a real signed Temporal worker. Fixture workers cannot certify the live cancel fence. Preserve existing workspace changes and document every unavailable prerequisite/gate.
