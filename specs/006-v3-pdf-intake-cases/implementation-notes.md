# Repository Notes and Fixed Boundaries: 006

- `LectureController` and `LectureRequest` belong to the existing lecture path. The controller stores to Laravel's `public` disk and request checks browser MIME/10 MiB. Neither is a V3 acceptance, privacy or owner gate. Keep V3 routes in 004's `routes/v3.php`; do not make V3 data reachable via `/lectures`, `/storage`, the legacy `TeacherAccessMiddleware` or an admin account.
- `config/filesystems.php` currently has a public symlink and a local disk that can serve URLs. Define a separate `v3_private` disk at `storage/app/v3` with `serve=false`, `throw=true`; its root must be outside the public symlink. A private path is still not authorization: the controller uses current 004 actor/policy and streams a verified file. The internal `AcceptedPdfReader::openForCase` also checks case→Document owner and ready status; 008 supplies any worker transport later.
- 004 registers policies explicitly in `AppServiceProvider`, supplies `HasV3Owner`, current-role checks, a singleton access lock and private/no-store errors. Use those exact implemented interfaces. 005's `SelectCaseSettings` first-writes its pointer; case insertion must be in the same transaction and after the 004 lock. Upload captures settings separately at receipt; both captures use immutable IDs and checksum verification.
- Current `config/queue.php` database connection has `after_commit=false` and test environment sync. Add a dedicated `v3_intake` connection/queue with `after_commit=true`; set worker timeout below `retry_after`. The scheduler in `routes/console.php` must run `v3:reconcile-intake` every minute. 006 scanner/storage retry uses fixed 60/120/240-second delays after the first attempt; do not consume 005 retry fields intended for 007. Queue dispatch is a convenience, not the sole durable record: committed attempts and pending Documents drive recovery.
- `pdfinfo` and `pdftotext` are installed in the reviewed environment, while `qpdf`, `clamdscan` and `clamscan` are absent. Do not silently substitute tools. qpdf and ClamAV must be provisioned for live acceptance. `pdftotext`/OCR belong to 008. Use Symfony Process argument arrays, time/output bounds and fixed failure codes; never shell-interpolate an uploaded filename or log tool output.
- Do not store original filename, PDF hash/path, malware signature, parser text or content in response/log/admin projection. 006 needs only safe attempt reason/state/timestamps plus owner and settings lineage. Hash is an internal exact-byte key and is unique only within one owner. Accepted bytes are retained for 008; quarantine has a 24-hour deadline, rejected bytes are purged. 015 may later add a retention policy without deleting referenced files/versions mid-case.
- 007 does not exist as application code yet. Its test fixture can read `awaiting_workflow`; do not create a production fake workflow row or mark the case queued in Temporal. 008 alone extracts text locally and calls NotebookLM `notebook_add_text`; 009 canonical prompts and eleven First-step Section fields are untouched. JEV Choice/Score/Noul and final-scene review are later concerns. V2, KOS/KIE and multitenancy remain outside 006.
- SQLite `:memory:` tests do not exercise competing processes. Use a shared file-backed DB or a production-equivalent DB for I09/I13/I15, ensure both requests overlap, and assert final row/file invariants. Tool doubles in recovery tests do not prove a live scanner connection.

- Do not use an automatically validating Laravel FormRequest for these POST contracts. It would reject before the controller records an upload attempt or checks Document visibility. Authorize via 004 middleware, create/resolve the resource in the controller/service, then run strict business-field validation with the named intake validators. Preserve CSRF before controller as the framework boundary.
- Extend 004's empty teacher workspace for the upload form and own attempt links. The attempt detail is the browser polling page. Render process only before any prior case; afterward render open-previous GET and an explicit process-again POST. Generate the case idempotency UUID in the rendered form so a browser resubmit repeats the same key.
