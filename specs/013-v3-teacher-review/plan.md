Once 004–012 are implemented, reuse 004 active-original-owner middleware and closed admin DTO, 005 captured settings, 007 HMAC/Temporal ReviewGate/event store, 008 `v3_private`, 009 Section, 010 current prompt/JEV/feedback adapter, 011 candidate resolver/collector and 012 eligibility/checker/repair ledger. Laravel alone persists and authorizes review/approval; Python manages ephemeral preview containers and durable workflow routing; Temporal stores only refs/status.

## Ordered design

1. Under case/Section lock, derive a review item from 012's **current** passing eligibility tuple; add a minute reconciler for lost 012 callbacks. Store one current Section pointer and historical items. Show exact prompt and eleven Section values only to 004's current active original owner.
2. Build the preview gateway by extending the 012 hardened checker image with a long-lived command loop per ephemeral session. Laravel forwards rehashed 011 files through the existing private signed bridge. The teacher browser receives only PNG frames and escaped semantic control labels, with owner authorization and CSRF at each action. Keep the gateway single-process/single-replica for pilot with eight-session cap; process restart expires sessions. Actual hostile-container tests prove egress and secret isolation.
3. Write each behavior's tests before its implementation: T002 covers current proof before the core schema/service, and T008 covers frame-0 approval, case-scoped idempotency, shared-DB race, stale/foreign denial and private note/atomic audit/outbox rollback before the decision service. Store one immutable decision and optional approval, route/outbox and proof-backed 007 event in one transaction. `approved_scene_count` counts current Section pointers, while old approval rows remain history.
4. Use the teacher's explicit category. Visual route extends 012's `repair_N` ledger and 011 repair payload with `RepairCriteriaV2` teacher note, under the same scene budget. Factual/mixed route extends 010 prompt origin/current pointer with a separate 013 teacher effect, but reuses the captured feedback template/provider, one-send uncertainty rules and 010 structural result parser. Both routes require a new candidate to pass 010/011/012 as applicable before a new review item.
5. Add a transactional outbox plus 007 ReviewGate per Section. The private bridge signals a committed decision by stable ID; query consumption after ambiguous delivery. A later correction to an approved Section always starts an idempotent `CorrectionWorkflow` with its own deterministic ID, even if the original case run is closed. A proof-backed 007 event may reopen `complete/approved` only for that committed owner correction; never mutate 007 status from an unverified worker claim.
6. Mark dormancy from case-captured days; keep owner assignment and private history. Exercise actual owner routes, V2/public bypass, active/inactive teacher, admin DTO, shared-DB race, real preview container, Temporal replay and selected live feedback provider. Stop rather than substitute a public iframe, active settings or a model classifier.

## Live evidence and deployment gates

The review service must have the 012 checker image rebuilt with 013 preview entry, an OCI runtime enforcing the same sandbox/no-network controls, a private signed bridge, and an actual 012-qualified disposable candidate. A mock PNG proves controller formatting only. A real scene action must change a frame in the container while malicious outbound requests fail; generated JS must not appear in the Laravel owner response or run in the app browser. A live Temporal worker must consume one owner decision and replay a duplicate without a second route. The factual correction gate must use the case-selected 005 approved feedback template/provider and actual credentials, then verify fresh 010 JEV and 011–012 handoffs. Missing provider/sandbox/Temporal capacity is an implementation blocker to report, not a reason to weaken the contract.
