## Recovery and stop conditions

If 004–012 delivered code differs materially from its signed contract, stop the dependent group and document the exact mismatch. If the preview container cannot enforce nonroot sandbox/no-network/no-secret controls or cannot render a representative 011 multi-file package, stop review approval work; do not switch to a same-origin scripted iframe or public disk. If selected captured feedback template/provider, 010 requalification, or Temporal is unavailable at final live gate, report that gate as unrun/failed; do not substitute active settings, another provider, a note classifier or a simulated JEV decision. Continue independent tests/docs where useful. A provider send reserved with uncertain outcome remains uncertain for 014 reviewed reconciliation; a decision signal timeout is queried and resent with the **same** decision ID/payload. Never create a second owner decision, review item, repair slot or prompt version to hide a lost acknowledgement. A gateway crash closes only ephemeral preview sessions; owner can reopen the same qualified item after recovery.
