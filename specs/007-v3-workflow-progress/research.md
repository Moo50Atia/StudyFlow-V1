# Research and Repository Evidence: 007

**Reviewed:** 2026-10-02. This is a documentation decision log; no Temporal/Laravel integration was run.

| Decision | Evidence and reason | Alternative not selected |
|---|---|---|
| Python Temporal SDK with a small private bridge | `composer.json` has Laravel 12/PHP ^8.2 and no Temporal PHP client; no Python V3 package exists. A Python SDK client/worker can start, describe, signal and test Temporal workflows ([SDK Client API](https://python.temporal.io/temporalio.client.Client.html), [worker/test API](https://python.temporal.io/temporalio.testing.WorkflowEnvironment.html)). Laravel still owns case identity/authorization. | Pretend Laravel already has a Temporal client or use a public browser endpoint |
| Deterministic ID with explicit reuse policy | SDK `start_workflow` defaults to `ALLOW_DUPLICATE` for closed ID reuse; [API reference](https://python.temporal.io/temporalio.client.Client.html) exposes `WorkflowIDReusePolicy.REJECT_DUPLICATE` and existing-handle/describe methods. The ID `v3-case-{case_id}` plus memo check makes timeout/duplicate starts reconcilable without another case. | Random workflow ID on each retry or assume timeout means not started |
| Laravel-first link and after-commit queue | 006 commits cases as `awaiting_workflow`, version 1, and deliberately does not call Temporal. Current `config/queue.php` database connection has `after_commit=false`; `routes/console.php` only has `inspire`. A link committed before HTTP plus one-minute discovery handles lost dispatch and partial success. | Remote start inside the case DB transaction |
| Explicit signed internal transport | `bootstrap/app.php` loads only web/console routes, and legacy `routes/web.php` has `teacher.access` routes where admin can view old content. A new `/api/internal/v1/case-events` route with HMAC avoids session/CSRF/admin-role confusion; a private Python bridge gives Laravel a concrete SDK boundary. | Put worker callback under teacher/admin web middleware |
| One transactional event/version projection | 006 case has `state_version=1` and immutable owner/Document/settings; 004 requires owner-scoped reads and closed admin summary. Unique `(case_id,event_key)` and `(case_id,sequence)` plus a case row lock avoid duplicate/stale regression. | Serve Temporal history directly to users or update case and event separately |
| Retry only 007-owned effect now | 005 [settings contract](../005-v3-versioned-settings/contracts/settings.md) defines `technical_retries` as **additional** 007 attempts and `retry_delay_seconds` as base. The Python SDK [RetryPolicy](https://python.temporal.io/temporalio.common.RetryPolicy.html) exposes `initial_interval`, coefficient, cap and maximum attempts. Laravel loads/checks the captured row and passes only its retry fields/checksum to Python; the callback activity is a real 007-owned side effect with an idempotent event key; 008–012 must prove their own external idempotency. | Claim Temporal replay alone makes NotebookLM/JEV/provider calls exactly once |
| Durable wait primitive with later authorization | The Python SDK supports workflow signals and `wait_condition` without occupying activity workers ([Python workflow guide](https://docs.temporal.io/develop/python)). 013 owns the real review record and active original-teacher action; 012 owns qualified candidate proof. 007 can test a reusable gate with a test-only workflow without production fake candidate/review rows. | Add a production ReviewSignal or candidate model before 012/013 |
| Honest early progress | 006 supplies no source adapter, while 008's [adapter contract](../008-v3-knowledge-source-adapter/contracts/knowledge-source-adapter.md) later binds extracted text to NotebookLM. A 007 case can prove startup and remain queued at extraction; no stage-completion percentage or synthetic source milestone is reported. | Add fake extraction/NotebookLM activity to make 007 appear end-to-end |

The official [Temporal CLI operator reference](https://docs.temporal.io/cli/command-reference/operator) documents namespace `update --retention` and `describe`; the [development server reference](https://docs.temporal.io/cli/command-reference/server) documents `--db-filename`. The future implementer must explicitly configure and inspect a disposable namespace before the 30-day reconciliation claim; the development server's default in-memory storage is insufficient for restart proof.

The current repository has no `v3_engine/`, Temporal dependency, V3 route, V3 case schema, internal callback or Temporal server binary in PATH. `phpunit.xml` uses SQLite `:memory:` and sync queue; those settings cannot prove separate-process event races or worker restart. `TeacherAccessMiddleware` grants legacy admin full content access, so 007 routes must use 004's V3 role/ownership boundary, not legacy middleware. Live completion requires a provisioned Temporal CLI/server or namespace, Python environment, bridge, callback key, queue worker and scheduler. The SDK test environment may download a CLI binary if no local path is supplied, so an offline test environment must provision that binary explicitly.

This design uses 004's teacher/admin boundary; local extraction and `notebook_add_text` stay in 008; NotebookLM mapping and unchanged canonical prompts/eleven Section fields stay in 009; successful typed JEV decisions remain direct 010/012 inputs; 013 owns teacher review; 014 owns admin commands; 015 owns full evidence/retention. V2 and KOS/KIE remain outside 007.
