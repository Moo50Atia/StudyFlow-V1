The source tool is a community integration and may use NotebookLM's evolving behavior. The current code shows no idempotency key on `notebook_create` or `notebook_add_text` and no source ID in add's result. It is an inference from those inspected tool definitions that an ambiguous call cannot be safely resent without reconciliation; the spec therefore allows only one automatic send. Exact source-content round trip and inventory completeness are live capability gates, not certified by repository reading. OCR and layout heuristics also cannot guarantee semantic preservation of arbitrary diagrams; the spec blocks detectable gaps and requires representative fixture checks.
