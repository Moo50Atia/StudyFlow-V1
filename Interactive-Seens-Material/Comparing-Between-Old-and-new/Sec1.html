Object-Oriented Implementation (C++) Class Encapsulation
class BankAccount {
private: double balance;
public:
BankAccount(double init) : balance(init) {}
void deposit(double amount) { balance += amount; }
bool withdraw(double amount) {
if (validationEnabled && amount > balance) return false;
balance -= amount; return true;
}
double getBalance() const { return balance; }
};
// External direct write attempt:
account.balance = proposedValue; // COMPILE ERROR
Access Control: Enforced by Compiler Validation: Implemented in withdraw()

3 Perspective 3: Encapsulation and Validation Solve Different Problems

Observe withdraw(150) from initial balance of 100 with validation enabled vs disabled.

Case A: Validation Enabled (Default)

Testing withdraw(150) from 100. Both procedural and OOP methods execute the check: amount > balance. Both reject the operation and retain 100.

Case B: Validation Disabled (Demonstration)

Testing withdraw(150) from 100 with validation condition intentionally omitted. Both sides become -50. This shows validation logic is not automatically created by OOP.
